# StarSlip

**Tap to slip free. Catch the next orbit.**

A one-tap arcade game. Your comet circles a planet. Tap to let go and fly into
the next planet's orbit. Grab stars for bonus points and beat your best score.

**Play:** https://brandon-ece.github.io/starslip/

**Install it like an app:**
- Android (Chrome): menu ⋮ → *Install app*
- iPhone (Safari): Share → *Add to Home Screen*

**Privacy:** StarSlip collects no personal data. See the [privacy policy](https://brandon-ece.github.io/starslip/privacy.html).
